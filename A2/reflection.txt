  To implement a P+7 technique that replaced all the nouns, I first need to check each word against an API of nouns. Next, I would split each line, checking each word and creating an array of nouns, one containing both individual nouns and another containing phrases of subsequent nouns. Eg. nouns like “snow plow” would go in the second list. This second list would then go through a function to check against an API if these phrases are nouns or if they are individual nouns, appending the results to the first list. Then I would send the items of this list to be replaced with their P+7 results via the token probability function in my code. Finally, I would place the nouns back into their respective places in the poem.
